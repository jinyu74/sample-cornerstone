## 사용자 보고 회귀: 도구 전환

- 확대 또는 이동 도구를 사용한 뒤 길이·각도·타원·닫힌 윤곽·메모로 전환하면 왼쪽 마우스는 선택한 주석 도구를 실행한다.
- 확대 뒤 선택 도구의 드래그는 영상을 확대하지 않는다. 밝기·대비는 VOI를 바꾸고 이동은 실제 영상 위치를 바꾼다.
- 오른쪽 확대·가운데 이동 보조 연결은 유지하되 이전 도구의 왼쪽 연결은 남기지 않는다.
- 회귀 테스트: `tests/e2e/tool-switching.spec.ts`. 수정 전 프로덕션에서 확대→길이 테스트가 결과0개로 실패하는 Red를 확인했다.

## 검증 fixture

공개·비식별 샘플 또는 합성 fixture 만 사용한다. 합성 DICOM 생성기는 테스트 코드에서 단일 프레임, 다중 파일 CT 스택(섞인 순서), 멀티프레임, 비DICOM, 미지원 transfer syntax 사례를 만든다.

## 2단위 추가 검증 항목

- Enhanced 멀티프레임: 방향·PixelSpacing 을 최상위 → Shared → PerFrame 순으로 읽고, PerFrame 값이 프레임마다 다르면 대표값을 두지 않고 `frameOrientations`·`framePixelSpacings` 로 보존한다. 프레임별 방향이 다르면 공간 스택으로 분류하지 않는다(검수 회귀 `parse-dicom-file.review.test.ts`).
- 시간 프레임: 위치가 모두 같으면 FrameTime/FrameTimeVector 가 있을 때 temporal, 없으면 unknown. 일부만 반복되면 unknown.
- NumberOfFrames 누락: PerFrame 기능 그룹이 2개 이상이면 `invalid-frame-count` 로 거부, 없으면 1 프레임.
- 동일 SOP UID 다른 바이트: conflict, 기존 원본·메타데이터 유지. 저장 실패(용량 초과): 트랜잭션 전체 취소, 기존 데이터 유지.
- 폴더 드롭: 하위 폴더 순회, 브라우저 entry 메서드 receiver 보존(검수 회귀 `collect-dropped-files.review.test.ts`), 읽기 거부 시 오류 표시.
- 뷰어 수명주기: 등록 대기 중 이탈·중간 실패 시 파일 해제(검수 회귀 `use-stack-image-ids.review.test.tsx`), 파괴된 엔진 render 방지, 오래된 render 이벤트 무시, 스택 전환 시 이전 오류 미표시.

## 3단위 검증 메모

- 상태의 "Green" 은 자동 테스트 통과를 뜻하며 Codex 최종 검수 전이다. 모든 검증은 합성 fixture 로 수행했다.
- 검수 회귀: 타원 공액 반지름, 검사별 저장 세션·빈 저장 후 편집, JSON 좌표계 선언, 주석 핸들 수정 반영(HandlesUpdated)과 소유 주석 정리, 썸네일 늦은 등록 해제, 지연 setImageIdIndex 중 이전 픽셀 render, 편집기 draft 와 외부 문서 변경 조율, 좌표 편집 후 world 좌표 정합성.
