# 화면 시각 기준

- 영상 작업 화면: `viewer-concept.png`. 이미지의 해부학·수치·샘플 행은 시각 참고용이며 제품에 가짜 영상이나 데이터로 넣지 않는다. 실제 DICOM을 가져온 결과를 표시한다.
- 검사 목록: `study-list-concept.png`(생성 후 추가). 실제 앱 최초 진입은 빈 목록이며 파일 가져오기 안내를 표시한다.
- 한국어 도구형 앱으로 구현한다. 마케팅 화면이나 장식용 통계는 추가하지 않는다.
- 작업 화면은 상단 도구 모음, 왼쪽 시리즈 목록, 중앙 검은 영상 viewport, 오른쪽 결과 목록·편집기, 하단 프레임 탐색 구조다.
- 검사 목록은 파일·폴더 가져오기, 드롭 영역, 검색·상태 필터, 검사 테이블 구조다.
- 기본 토큰: 배경 흰색, 보조 표면 차가운 slate 계열, 기본 글자 진한 slate, 경계 `#e2e8f0`, 강조 `#0d9488`, 작은 모서리 반경 6px. shadcn semantic token으로 선언한다.
- 13~14px 도구·본문 글자와 뚜렷한 대비를 사용한다. 강조색은 선택 상태·현재 도구·주요 동작에 제한한다.
- viewport는 실제 Cornerstone 렌더링 영역이다. 측정값은 실제 좌표와 보정 정보에서 계산한다.
- 화면 너비가 줄면 사이드 패널을 접근 가능한 Sheet 등으로 전환하고 도구 모음이 영상과 주요 동작을 가리지 않도록 한다.
- UI 텍스트·컨트롤은 HTML/React로 구현한다. 컨셉 이미지를 제품 UI나 DICOM 렌더링 대용으로 사용하지 않는다.
- 컨셉과 렌더링을 동일 QA 단계에서 비교하고, 기능상 필요한 차이는 검수 기록에 명시한다. 반응형·빈 상태·저장 실패·지원 불가 형식은 같은 디자인 토큰을 적용한다.
- 접근성 조정(허용된 컨셉 차이): `#0d9488` 배경 위 흰 글자는 대비 3.74:1 로 작은 텍스트 AA(4.5:1) 에 부족하다. 텍스트가 올라가는 강조 배경(`--primary`)은 `#0f766e`(5.47:1)를 쓰고, `#0d9488` 은 `--brand` 토큰으로 선택선·아이콘·장식(비텍스트 3:1)에만 쓴다. 포커스 링(`--ring`)은 `#0d9488` 을 유지한다.
